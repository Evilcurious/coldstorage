# Tahseen Jaber Cold Storage

Corporate website for Tahseen Jaber Cold Storage — next-generation cold chain and logistics infrastructure in Uuayrij Industrial Area, Baghdad.

## Stack

- Next.js (App Router)
- Tailwind CSS
- Lucide React

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Vercel

This is a Next.js App Router app. In Vercel:

1. Framework preset: **Next.js** (not Other)
2. Production branch: `main` (or `arena/81ec7350-coldstorage`)
3. Root directory: repository root (leave empty)
4. Build command: `next build`
